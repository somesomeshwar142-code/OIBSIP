# 🛠️ CyberSecurity Task 6: The Importance of Patch Management

## 📌 Overview
This directory contains a formal, academic-grade research report examining **Enterprise Patch Management**, vulnerability lifecycles, real-world failure case studies, compliance implications, and organizational deployment methodologies.

The report details CVE assignment mechanics, CVSS v3.1/v4.0 scoring, documented breach analyses (*WannaCry/EternalBlue* & *Equifax Data Breach*), the 5-phase patch lifecycle, a 7-step operational checklist, and strategies for patching legacy systems without downtime.
