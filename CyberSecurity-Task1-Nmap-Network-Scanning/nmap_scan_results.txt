4. DETAILED OPEN PORT SECURITY RISK ANALYSIS
================================================================================

[PORT 21 / TCP] - FTP (vsftpd 2.3.4)
--------------------------------------------------------------------------------
• Service Description: File Transfer Protocol (FTP) used for uploading and downloading files.
• Security Risk Level: HIGH / CRITICAL
• Vulnerability & Risk Analysis:
  - Version vsftpd 2.3.4 contains a famous smile backdoor vulnerability (CVE-2011-2523).
  - FTP transmits credentials and data in cleartext unless wrapped in TLS/SSL (FTPS).
  - Susceptible to credential sniffing, brute-force attacks, and unauthenticated remote shell access.
• Recommendation: Upgrade vsftpd to a secure version or replace with SFTP (SSH File Transfer Protocol). Disable anonymous FTP access.

[PORT 22 / TCP] - SSH (OpenSSH 4.7p1)
--------------------------------------------------------------------------------
• Service Description: Secure Shell (SSH) for encrypted remote terminal access and administration.
• Security Risk Level: MEDIUM
• Vulnerability & Risk Analysis:
  - OpenSSH 4.7p1 is an outdated release vulnerable to user enumeration and legacy cipher suite weakness.
  - Open SSH ports are frequent targets for automated password brute-forcing and dictionary attacks.
• Recommendation: Disable root login via SSH (`PermitRootLogin no`), enforce key-based authentication (RSA/Ed25519), change default port 22, and implement Fail2ban rate limiting.

[PORT 80 / TCP] - HTTP (Apache httpd 2.2.8)
--------------------------------------------------------------------------------
• Service Description: Hypertext Transfer Protocol (HTTP) web server hosting web applications.
• Security Risk Level: MEDIUM / HIGH
• Vulnerability & Risk Analysis:
  - Transmits data unencrypted over HTTP, making session cookies and passwords vulnerable to Man-In-The-Middle (MITM) attacks.
  - Apache 2.2.8 is obsolete and contains multiple known CVEs (DoS, buffer overflows).
• Recommendation: Force HTTP to HTTPS redirection (301 redirect), update Apache to the latest stable release, and enforce Strict-Transport-Security (HSTS).

[PORT 443 / TCP] - HTTPS (Apache httpd 2.2.8 TLS/SSL)
--------------------------------------------------------------------------------
• Service Description: HTTP Secure (HTTPS) encrypted web communications.
• Security Risk Level: LOW / MEDIUM
• Vulnerability & Risk Analysis:
  - Encrypts web traffic, protecting against eavesdropping.
  - Older SSL/TLS implementations (SSLv3, TLS 1.0, TLS 1.1) may be vulnerable to Heartbleed, POODLE, or weak cipher suite attacks.
• Recommendation: Configure web server to support only TLS 1.2 and TLS 1.3, disable SSLv3/TLS1.0/1.1, and install valid TLS certificates from a trusted CA.

[PORT 3306 / TCP] - MySQL Database (MySQL 5.0.51a)
--------------------------------------------------------------------------------
• Security Description: Relational Database Management System (RDBMS).
• Security Risk Level: HIGH
• Vulnerability & Risk Analysis:
  - Exposing database ports directly to external networks exposes the database to brute-force attacks and authentication bypass bugs.
  - Outdated MySQL version 5.0.51a has known privilege escalation vulnerabilities.
• Recommendation: Bind MySQL service exclusively to localhost (`127.0.0.1`), use strict firewall rules (UFW/iptables), and enforce strong database password policies.

[PORT 8080 / TCP] - HTTP-ALT / Proxy (Apache Tomcat JSP Engine 1.1)
--------------------------------------------------------------------------------
• Security Description: Alternative HTTP web server port often used for web proxies, admin panels, or Java application servers.
• Security Risk Level: MEDIUM / HIGH
• Vulnerability & Risk Analysis:
  - Often hosts administrative manager apps or debugging interfaces with default admin credentials (e.g. tomcat:s3cr3t).
  - Unencrypted traffic over 8080.
• Recommendation: Restrict access via IP whitelisting or local binding, enforce strong authentication credentials, and place behind a reverse proxy with TLS encryption.
